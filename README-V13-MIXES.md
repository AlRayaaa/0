# Alraya V13 — Cloud Mixes

## ما تم إصلاحه
- خلطات العطور تُحفظ في Supabase عبر RPC `save_mixture`.
- الوصف يُحفظ في عمود `mixes.desc` ويظهر في القائمة والتفاصيل.
- أسماء 2 إلى 10 عطور تُحفظ في `mix_items`.
- التعديل والحذف والمزامنة الفورية عبر Realtime.
- ترقية الجداول القديمة بدون حذف بيانات الخلطات.
- رسائل أخطاء أوضح إذا كان جدول `mixes` أو `mix_items` أو دالة `save_mixture` ناقصة.
- زر نسخ كود قاعدة البيانات داخل الموقع يتضمن إعداد الخلطات أيضاً.

## التثبيت
1. إذا كانت قاعدة Supabase جديدة: شغّل `supabase-setup.sql` كاملاً.
2. إذا كانت قاعدة Supabase موجودة من V8/V11/V12: شغّل `supabase-update-v13-mixes.sql` مرة واحدة.
3. ارفع ملفات V13 إلى GitHub.
4. سجّل الدخول ثم أضف خلطة واكتب الوصف.
5. بعد الحفظ يجب أن تظهر رسالة `تم حفظ الخلطة سحابياً`.
