# الراية للعطور — نسخة PWA قابلة للتثبيت

هذه النسخة مهيأة لتظهر كـ **تطبيق قابل للتثبيت** من المتصفح، مع أيقونة واختصار على الهاتف/الكمبيوتر.

## طريقة النشر
ارفع جميع ملفات المشروع إلى GitHub Pages أو أي استضافة HTTPS.

> مهم: التثبيت من المتصفح يحتاج الموقع أن يعمل عبر HTTPS (مثل GitHub Pages).

## على Android / Chrome
1. افتح رابط الموقع بعد نشره.
2. انتظر تحميل الصفحة.
3. إذا ظهر زر **📲 تثبيت التطبيق** داخل الموقع اضغط عليه.
4. أو افتح قائمة Chrome **⋮** ثم اختر **تثبيت التطبيق** / **إضافة إلى الشاشة الرئيسية** حسب إصدار Chrome.
5. سيظهر اختصار باسم **الراية للعطور** ويفتح الموقع كأنه تطبيق مستقل.

## ملاحظات
- تسجيل الدخول يبقى محفوظاً بواسطة إعدادات Supabase الموجودة في `app.js`.
- الـ Service Worker مخصص لتجهيز التطبيق للتثبيت وتخزين ملفات الواجهة الأساسية مؤقتاً.
- بيانات Supabase تبقى عبر الإنترنت؛ لا يعتمد النظام على الكاش لحفظ بيانات قاعدة البيانات.
