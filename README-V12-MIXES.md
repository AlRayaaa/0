# الراية للعطور — V12

هذه النسخة تجعل خلطات العطور تحفظ في Supabase عند توفر الاتصال السحابي، ولا تسقط بصمت إلى الحفظ المحلي إذا كانت جداول الخلطات غير جاهزة.

## التشغيل
1. افتح Supabase SQL Editor.
2. شغّل `supabase-update-v12-mixes.sql` بالكامل.
3. تأكد أن المستخدم يسجل الدخول.
4. افتح الموقع وأضف خلطة. ستظهر رسالة `تم حفظ الخلطة سحابياً`.

الخلطة تشمل: الاسم، الوصف، النوع، الصورة، ومكونات الخلطة.
