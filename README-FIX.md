# إصلاح photo_path وتحسينات النسخة النهائية

## تم التحقق من المشكلة
سبب الخطأ الأصلي أن بعض نسخ قاعدة بيانات Supabase لا تحتوي عمود `photo_path`، بينما كانت النسخة السابقة من التطبيق ترسله عند حفظ المنتج.

في هذه النسخة تم إزالة `photo_path` بالكامل من البيانات التي يرسلها `app.js` إلى جدول `products`، لذلك لن يحتاج حفظ أو تعديل المنتج إلى هذا العمود.

## تحسينات إضافية
- منع رفع ملفات ليست صوراً.
- الحد الأقصى لحجم صورة المنتج: 5 ميغابايت.
- رسائل أوضح لأخطاء `photo_path`.
- تنظيف اتصال Realtime عند تسجيل الخروج لمنع بقاء قناة قديمة مفتوحة.
- فحص JavaScript نحوياً قبل تجهيز النسخة.

## إذا ظهر الخطأ بعد رفع النسخة الجديدة
غالباً المتصفح ما زال يستخدم ملفات JavaScript القديمة. حدّث الصفحة تحديثاً قوياً أو امسح الكاش ثم جرّب مرة أخرى.

## ملف SQL المرفق
`supabase-fix-photo-path.sql` اختياري لهذه النسخة، لكنه آمن للتشغيل إذا أردت أيضاً تحديث قاعدة البيانات القديمة وإضافة العمود.


## تحديث عرض المنتجات
- إزالة عبارة الاتصال بالسحابة من الواجهة.
- عرض بطاقتين للمنتجات في كل صف على الشاشات المتوسطة والكبيرة، وبطاقة واحدة على الهاتف.
- إظهار المعلومات المهمة داخل بطاقة المنتج مباشرة: الحجم، التركيز، بلد الصنع، المورد، الكود والباركود عند توفرها.
- إظهار وصف مختصر للمنتج داخل البطاقة مع الحفاظ على التفاصيل الكاملة في نافذة «التفاصيل».
