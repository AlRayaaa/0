# الراية للعطور — GitHub Pages + PWA

## رفع المشروع إلى GitHub
1. أنشئ Repository جديد.
2. ارفع **كل الملفات الموجودة في هذا المجلد** إلى جذر الـ Repository، بحيث يكون `index.html` في الجذر.
3. من **Settings → Pages** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/ (root)` ثم Save.
5. افتح رابط GitHub Pages عبر HTTPS.

## التثبيت كتطبيق
المشروع مجهز بـ `manifest.json` و`sw.js` و`pwa.js`.
على Chrome/Edge في Android سيظهر زر **التثبيت وإنشاء اختصار** ويمكن استخدام نافذة التثبيت الأصلية عندما يدعمها المتصفح.
إذا لم يظهر طلب التثبيت تلقائياً، الزر يوضح للمستخدم مكان **تثبيت التطبيق / إضافة إلى الشاشة الرئيسية** في قائمة المتصفح.

> ملاحظة: GitHub Pages يجب أن يعمل عبر HTTPS حتى يعمل Service Worker والتثبيت كـ PWA.
