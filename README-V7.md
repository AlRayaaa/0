# الراية للعطور — V7

تم دمج التعديلات المطلوبة داخل نسخة واحدة:
- إزالة قوائم المبيعات والمشتريات والتقارير من الواجهة.
- إضافة قائمة نقوصات مع إضافة/تعديل/حذف وتحديد تم الشراء.
- إضافة إدارة الديون مع الكلي والمدفوع والمتبقي.
- دعم التخزين المحلي وSupabase.
- أضفنا `supabase-update-v7.sql` لتحديث قاعدة البيانات الحالية.
- `supabase-setup.sql` محدث للمشاريع الجديدة.

إذا كانت قاعدة Supabase موجودة مسبقاً، شغّل `supabase-update-v7.sql` مرة واحدة فقط.

## إصلاح النقوصات
إذا ظهر الخطأ `Could not find the table 'public.shortages' in the schema cache`، شغّل ملف `supabase-fix-shortages.sql` في Supabase SQL Editor مرة واحدة ثم حدّث الموقع. النسخة الحالية تحتوي أيضاً على وضع احتياطي يحفظ النقوصات محلياً مؤقتاً إذا كان جدول Supabase غير مفعّل، بدلاً من إظهار خطأ عند الضغط على حفظ.
