# الراية للعطور — V5.4

نسخة إدارة مخزون ومبيعات سحابية عبر Supabase.

## تشغيل النسخة الحالية
1. افتح Supabase SQL Editor.
2. إذا كانت قاعدة البيانات جديدة: شغّل `supabase-setup.sql` بالكامل.
3. إذا كانت قاعدة بياناتك موجودة من نسخة سابقة: شغّل `supabase-update-v5.4.sql` فقط.
4. حدّث موقع GitHub/الاستضافة بملفات المشروع كاملة.
5. أنشئ حسابًا جديدًا من الموقع.

## مهم
- `config.js` يحتوي Project URL وPublishable key فقط. لا تضع Secret/Service Role داخل الموقع.
- إذا كان تأكيد البريد مفعّلًا في Supabase، يجب تأكيد البريد قبل أول تسجيل دخول.
- تغيير البريد قد يطلب تأكيد البريد الجديد.

## ما تم إصلاحه
- إضافة `photo_path` للمنتجات.
- إنشاء سجل نشاط وتعديلات.
- اسم المستخدم الذي أضاف/عدّل الصنف.
- فرز وفلاتر المخزون.
- عمليات البيع والشراء الذرّية لمنع نقص المخزون عند فشل تسجيل العملية.
- منع تكرار الباركود وكود الصنف على مستوى قاعدة البيانات.
